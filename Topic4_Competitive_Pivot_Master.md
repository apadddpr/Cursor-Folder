## Cursor differentiators (base all pivots on this)

From Cursor prep / enterprise positioning:

| Pillar | What it means for Mercury |
|--------|---------------------------|
| **AI-native IDE** | Editor + codebase index + agents in one product, not a plugin |
| **Codebase context** | Monolith + Central integration = needs repo-wide understanding |
| **Agentic, multi-file work** | Cross-squad changes span routes, services, tests, configs |
| **Rules (.cursor/rules)** | DevEx codifies standards once; every dev and agent follows them |
| **Model agnostic** | OpenAI, Anthropic, Google, x.ai; not locked to one vendor |
| **Adoption / IDE UX** | VS Code familiar; works for mixed skill levels across ~58 eng |
| **Privacy Mode + SOC 2** | Fintech; Branden review; trust.cursor.com |
| **Bugbot** | Review bottleneck as AI output scales |
| **Enterprise controls** | SSO, model/MCP allowlists, admin analytics |
| **Customer proof** | Brex, OnePay (fintech), Rippling (DevEx scale), Faire (agents), Sentry (org-wide) |

**One-liner:** Copilot is strong in-file. Claude Code is strong in the terminal. Cursor is the full workspace where you standardize AI across the org.
