## 4 core differentiators (priority order)

### 1 · Model neutrality
- Best model changes over time · customers want optionality
- Not locked to one provider
- **Say:** "Teams want access to the best models over time without leaving their workflow behind."

### 2 · Large codebase performance
- Not just wrapping a model · improves how context is found and used
- Semantic Search · Dynamic Context Retrieval
- **Say:** "As codebases get larger and messier, how context is found and used matters more than the model alone."

### 3 · Faster time to value
- Works out of the box · standardize faster across teams
- Power users go deep · baseline is already strong
- **Say:** "Enterprises care about adoption. Not every developer should have to invent their own setup."

### 4 · Platform, not just a tool
- Full SDLC: plan, write, review, debug, iterate
- Bugbot · Agent Review · Automations
- **Say:** "The value is not just better answers. It is better execution and iteration where developers actually work."

## vs GitHub Copilot (prep doc framing)

| Copilot | Cursor |
|---------|--------|
| Snippet help | **Task completion** |
| Local suggestions | **Broader codebase context** |
| Isolated assistance | **Workflow support** |
| Point solution | **Integrated development experience** |

**Position:** Copilot helps developers write code faster. Cursor is an AI-native environment for completing broader tasks across a codebase.

**Lead differentiators:** #2 Large codebase · #4 Platform · #3 Time to value
